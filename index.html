ゆるぼ プライバシーポリシー

最終更新日: 2026年8月15日

「ゆるぼ」（以下「本アプリ」）は、友だちに「今日ちょっと集まりたい」という気分を共有するためのアプリです。本ポリシーは、本アプリが取得する情報とその取り扱いを説明します。

取得する情報と利用目的

情報 何を取得するか なぜ取得するか どこに保存されるか いつ削除されるか
メールアドレス サインアップ時に入力されたメールアドレス アカウントの識別・ログイン・パスワード再設定・メールアドレス確認 Supabase Auth アカウント削除時に即時削除
パスワード ログイン用パスワード（ハッシュ化して保存し、平文では保持しません） ログイン認証 Supabase Auth アカウント削除時に即時削除
表示名 ユーザーが設定する表示名 友だちの一覧・通知・回答一覧での表示 Supabase Database アカウント削除時に即時削除
アバター画像 URL プロフィール画像の URL プロフィール表示 Supabase Database アカウント削除時に即時削除
プッシュ通知トークン 端末ごとに OS が発行するプッシュ通知トークン 友だちからのゆるぼをプッシュ通知で届けるため Supabase Database アカウント削除時に即時削除
友だち関係 誰と誰が友だちかという情報と、各ユーザーが付けた備考・既定送信先の設定 送信先の候補一覧の表示、通知の宛先決定 Supabase Database アカウント削除時に即時削除。友だち解除時は該当の関係のみ削除
シグナル（ゆるぼ） 集まりのタイプ（飲み / ランチ / その他）、送信日時、有効期限、状態 友だちへの共有と、当日の集まりの調整 Supabase Database 有効期限を過ぎると「期限切れ」になりますが、記録としては残ります。アカウント削除時に削除
送信先・回答 誰に送ったか、受け取った人の回答（行ける / たぶん行ける / 今日は無理） 送信者への回答状況の表示 Supabase Database アカウント削除時に削除
クラッシュ情報 エラーのスタックトレース、アプリのバージョン・ビルド番号、デバイス・OS の情報 不具合の調査と修正 Sentry Sentry のデータ保持期間の経過後に削除

取得しない情報

  • 位置情報・連絡先・カレンダー・写真ライブラリへはアクセスしません。
  • カメラは友だち追加の QR コード読み取りのときだけ使用し、撮影した画像を保存・送信することはありません。
  • 広告 ID の取得や、広告目的でのトラッキングは行いません。
  • クラッシュ情報には、メールアドレスや各種トークン（プッシュ / アクセス / リフレッシュ / ID トークン等）を含めません。送信前に自動で除去しています。

第三者への提供

ユーザーの情報を第三者へ販売・貸与することはありません。以下のサービスを、本アプリの提供に必要な範囲で利用しています。

サービス 渡す情報 目的
Supabase 上表の「Supabase」に保存される情報すべて 認証・データベースの提供
Expo Push Service プッシュ通知トークン、通知の件名・本文 プッシュ通知の配信
Apple（APNs）/ Google（FCM） プッシュ通知トークン、通知の件名・本文 端末へのプッシュ通知の配送
Resend メールアドレス、メール本文 確認コード・パスワード再設定メールの送信
Sentry クラッシュ情報 不具合の調査

友だちに見える情報

本アプリは友だち同士で情報を共有する仕組みのため、以下は友だちに見えます。

  • 表示名・アバター画像
  • 自分が送ったゆるぼの内容（集まりのタイプ）と、それを送った相手に対する送信状況
  • 自分が受け取ったゆるぼへの回答（送信者に見えます）

メールアドレスが他のユーザーに表示されることはありません。

データの保存期間

  • アカウントに紐づく情報は、アカウントが存在する間保存されます。
  • 送信済みのゆるぼは有効期限（送信した日の翌 0 時）を過ぎると「期限切れ」状態になりますが、記録としては残ります。期限切れだけを理由に自動削除されることはありません。
  • クラッシュ情報は Sentry 側の保持期間に従って削除されます。

アカウントの削除

アプリの 設定 → アカウント削除 からいつでも削除できます。削除すると、次がすべて即座に削除されます。

  • 認証情報（メールアドレス・パスワード）
  • プロフィール（表示名・アバター画像 URL・プッシュ通知トークン）
  • 友だち関係と友だちごとの設定
  • 送信・受信したゆるぼ、送信先、回答

削除は取り消せません。なお、既に端末に配信済みのプッシュ通知は端末側に残ることがあります。また、削除前に取得済みのクラッシュ情報は Sentry の保持期間の経過まで残ります。

セキュリティ

  • 通信はすべて暗号化（HTTPS）されています。
  • データベースは行レベルセキュリティ（RLS）により、ログインしているユーザーが参照・更新できる範囲を制限しています。
  • パスワードはハッシュ化して保存し、平文では保持しません。

子どものプライバシー

本アプリは 13 歳未満の方の利用を想定していません。

本ポリシーの変更

本ポリシーを変更する場合は、本ページを更新します。重要な変更がある場合はアプリ内でお知らせします。
